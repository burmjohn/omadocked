# Omadocked accessibility limits

- Keyboard: Omarchy menu is first, Settings next. Return on Settings opens the panel; Escape or a click outside closes it. Right-click empty shelf still opens Settings if the icon is hidden.
- Reduced motion: disables wave/zoom animation and launch bounce hops; attention uses a small pip during the finite pulse and does not leave a frame around the icon.
- Contrast: theme colors from Omarchy; no separate high-contrast palette.
- Labels: optional app names; Omarchy caption is “Omarchy”; Settings caption is “Settings”; icon-only when names are off.
- Screen readers: Accessible names on Omarchy, Settings, size, transparency, and the Settings-icon checkbox. No full AT-SPI audit.
