# Omadocked accessibility limits

- Keyboard: shelf focus, Settings from the Settings icon, Return/Escape, and right-click empty shelf still open Settings if the icon is hidden.
- Reduced motion: disables wave/zoom animation and launch bounce hops; attention uses a small pip during the finite pulse and does not leave a frame around the icon.
- Contrast: theme colors from Omarchy; no separate high-contrast palette.
- Labels: optional app names; Settings caption is “Settings”; icon-only when names are off.
- Screen readers: Accessible names on Settings, size, transparency, and the Settings-icon checkbox. No full AT-SPI audit.
